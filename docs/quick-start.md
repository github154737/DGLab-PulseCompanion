# 用户快速开始

## 已受邀参加内测

继续使用维护者提供的内测安装包和内测码。无需填写服务器、API 密钥或证书。管理员入口与普通用户权限保持分离。

## 使用公开自部署版

公开版开屏后直接进入服务配置，没有内测登录。普通用户不需要安装 Python、Rust、Flutter 或租服务器。

有服务提供者给的连接文件时：

1. 点击「导入连接文件」，选择提供者发来的 JSON 文件。
2. 核对页面显示的服务器地址，再点「进入应用」。文件不会自动启动网络请求、打开开发工具或授权实物输出。

自己直连 Venice 时：填写自己的 API 密钥，点击「进入应用」。能否直连取决于当前手机网络。自己的 API 费用由对应账户承担。

没有密钥时可「先离线浏览」。高级证书和开发工具默认收起。普通使用不需要开启开发工具；管理员身份也不等于设备输出授权。

配置仅保存在本次运行内，退出服务或重启后重新导入文件/填写密钥。连接文件包含访问令牌，应按密码保管；应用不会后台读取剪贴板，也不会把它保存到普通设置文件。目前没有实现系统密钥库的“记住配置”。

## 连接设备

进入「互动」→「连接设备」，按页面提示在 DG-LAB 配对；若浏览器跳转受系统限制，可使用配对二维码。设备连接后选择对应设备，显式启用实物输出。先从零开始，确认停止按钮、连接状态与强度上限；模型回复不代表设备已执行，以执行回执为准。

电脑无需一直开机的前提是配置使用可访问的云中继。Wi-Fi 与移动网络的跨境链路可能不同，换网络后可在连接检测中确认服务是否可达。

## 服务提供者如何发连接文件

已有外部云中继配置时，在项目根目录运行：

```powershell
python scripts/export-connection.py
```

默认写入 `%USERPROFILE%/.aihaptics/connections/relay.connection.private.json`，不会上传、自动发送或回显密钥；已有文件不覆盖。可以用 `--config` 指定其他外部配置，`--output` 指定仓库外的新文件。只需把生成的连接文件私下交给用户，不需要发送 Venice 供应商密钥。

当前中继访问令牌是共享凭据，不是逐用户账户。若要扩大试用，应先实现逐用户令牌、撤销和配额。更换共享令牌会影响使用旧文件/旧内测包的全部用户。
