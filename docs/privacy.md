# 数据流与本地存储

公开版默认没有项目方服务器配置。填写自己的 Venice API 密钥后，文本上下文、控制规划和导答所需信息会发送到 Venice；语音转写上传当前录音片段，朗读会发送待合成文本。使用中继时先经过所选中继，再到上游。设备状态与执行回执可能进入模型上下文，用于解释实际执行结果。

内测版使用维护者预设中继。开源许可证不决定云服务商的数据留存政策，使用者应另行阅读所选供应商说明。

连接密钥在本次应用运行内使用；退出服务后清除，公开配置页不会将其写入普通偏好文件。用户保存的连接文件本身包含中继访问凭据，应自行保管。应用本地会保存昵称、语音偏好、强度限制、波形分类/收藏/候选项及导入的波形文件。

持续对话须主动开启，可静音、结束或撤销系统麦克风权限。轻哼/无明确文字不应作为自动增加强度的授权。后台行为受系统权限及电池策略影响，不宣称所有手机均支持同样行为。

诊断默认隐藏于普通用户；开发模式记录阶段、耗时、错误类别、请求标识、长度、控制目标、回执与状态，不记录录音、完整聊天正文或密钥。当前内存诊断有条数上限，关闭进程后不保留。截图、导出的文件与用户主动复制的日志由用户掌控。

设备协议可经 DG-LAB 的服务传输，应用和设备服务均有自己的连接边界。应用内显示“已连接”或模型口头答复不等价于设备实际电流测量。

这份说明描述当前实现，不承诺操作系统、网络运营者或第三方云服务不会保留其自身日志。不要在公开 issue 附上 API 密钥、连接文件、录音或完整私人对话。
